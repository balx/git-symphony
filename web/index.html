git-symphony

Turn a GitHub repository's history into a minute of music. Every commit is a note, every top contributor an instrument, every release a cymbal swell.

GitHub token

GitHub only shares commit history with signed-in requests, so this page needs a token. Create a fine-grained token and keep the default public, read-only access. It stays in this browser and is only sent to api.github.com.

Enter a repository to hear its history.Try expressjs/express or your own project.

The page picks each note's starting pitch from the commit subject, since GitHub's API does not list changed files. For the version that reads changed files from a local clone, run npx git-symphony path/to/repo --video.
